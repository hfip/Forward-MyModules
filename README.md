# Forward — My Modules

Arabic-first modules for the **Forward** player: channel packs, widgets and metadata fixes.

## Contents

| Path | What it is |
|---|---|
| `forward-widgets.fwd` | Packed module bundle for Forward |
| `manifest.json` | Module manifest (names, icons, entry points) |
| `scripts/module1.js` … `module7.js` | Individual module scripts |
| `assets/icon.png` | Pack icon |

## Install

1. Import `forward-widgets.fwd` in Forward, **or**
2. Add the scripts one by one from `scripts/`.

## Included modules

- Arabic channel directories
- Widgets for home-screen rows
- Title / poster metadata fixes for Arabic content

## Notes

- Scripts run inside Forward; review them before importing.
- Sources may change over time — open an issue if a module stops returning results.
