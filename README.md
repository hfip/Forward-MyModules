### 📝 وصف الحزمة
مجموعة وحدات وأدوات مخصصة لتطبيق **Forward** بنسخة عربية متكاملة، تتيح لك تصفح ميتاداتا الأفلام والمسلسلات وجداول القنوات التلفزيونية والوصول للروابط الرسمية بكل سلاسة بالاعتماد على بيانات TMDB.

### 📺 الأدوات المتضمنة بداخل الحزمة:
1. **القنوات العربية 📺:** قوائم المسلسلات والأفلام العربية مع دليل شامل لجدول القنوات التلفزيونية الفضائية (مثل MBC ونشيونال جيوجرافيك وغيرها).
2. **شاهد VIP 🎬:** تصفح ميتاداتا مسلسلات وأفلام منصة شاهد بالبوسترات الأصلية والروابط الحقيقية المباشرة لتشغيل الميديا.
3. **⭐ نجوم هوليوود والمخرجون:** تصفح واستكشاف أعمال أشهر 54 ممثل ومخرج عالمي في مكان واحد مع ميزة البحث الحر.
